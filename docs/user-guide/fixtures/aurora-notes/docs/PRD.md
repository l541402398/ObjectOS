# 产品需求：Aurora Notes

## 目标

为个人知识工作者提供一款离线可用、可追溯、可扩展的 Markdown 笔记工具。

## 核心场景

1. 快速记录与全文检索。
2. 通过双向链接形成知识图谱。
3. 在多设备之间安全同步，不泄露明文。

## 非目标

- 多人实时协同编辑。
- 插件市场。
- 移动端原生应用（M3 前不投入）。

## 验收基线

- 冷启动 500ms 内可编辑。
- 10,000 篇笔记的全文搜索 P95 < 150ms。
- 崩溃后最近 30 秒内的编辑不丢失。

## 当前里程碑 M2：检索体验

- 搜索支持标签过滤。
- 搜索结果返回带高亮的摘要片段。
- 以上能力必须有单元测试覆盖。
