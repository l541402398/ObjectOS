## 2. 缺口与实施决策

- 新增 `project-analyzer`：扫描工作区，识别 TS/React/Electron/Vite 与 Java/Maven/Gradle；读取 package.json/pom，不读取源码内容。
- 新增 `planning`：本地规则生成可编辑 PlanDraft（明确 `generatedBy: local-rules`），审批后复用 TaskService 创建真实任务与依赖；不假装是模型生成。
- 新增 `graph-projection`：只用 SQLite 的 tasks/dependencies/agents/runs/events 构节点边；React Flow 仅投影，不改任务 DAG。
- 图布局保存到 `graph_layouts`，不参与调度。
- 本期不做：Worktree、自动合并、完整质量门禁、自动 Agent 调度链、200 节点压测。
- UI：新增“编排工作台”；设置新增连接改为**内联编辑视图**，不再叠加二层 Modal。

## 3. 迁移风险

- v3 仅新增 `project_snapshots`, `plan_revisions`, `graph_layouts`；不改 v1/v2 表。
- 计划审批创建任务必须事务化；失败不得留下半套 DAG。
- 图布局丢失可自动重排，不影响真实任务依赖。
- 扫描失败不能让 Runtime 崩溃；返回结构化警告。
